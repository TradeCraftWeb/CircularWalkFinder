# 🥾 Circular Walk Finder

**Discover circular walking routes near any UK postcode.**  
Powered by [OpenStreetMap](https://www.openstreetmap.org) data via [OpenRouteService](https://openrouteservice.org), with interactive maps from [Leaflet.js](https://leafletjs.com).

👉 **[Live Demo on GitHub Pages](#)** *(update this link after deploying)*

---

## Features

- 📍 **UK Postcode geocoding** via [postcodes.io](https://postcodes.io) (no key needed)
- 🗺️ **Circular route generation** using OpenRouteService's round-trip algorithm
- 🥾 **% Footpath estimate** — how much of each route is on footpaths, tracks, and bridleways (vs roads)
- 🔄 **Repetition score** — how "loopy" the route is (low = clean loop, high = lots of backtracking)
- 🌿 **Natural surface estimate** from OpenStreetMap surface data
- ⏱ **Estimated duration** at a walking pace of 5 km/h
- 📏 **Max stray radius** — filters out routes that venture too far from your start point
- 🔢 **Sort & compare** routes by distance, footpath %, repetition, or duration
- 🌙 **Dark / light mode** with system preference detection
- 📱 **Responsive** — works on desktop and mobile

## Quick Start

### 1. Get a free ORS API key

1. Go to [openrouteservice.org/dev/#/signup](https://openrouteservice.org/dev/#/signup)
2. Create a free account
3. Go to your [Dashboard → Tokens](https://openrouteservice.org/dev/#/home)
4. Copy your default token

**Free tier limits:** 2,000 requests/day · ~40 requests/minute

### 2. Use the site

1. Open `index.html` in a browser (or deploy to GitHub Pages — see below)
2. Paste your ORS API key into the **🔑 API Key** field and click 💾 to save it locally
3. Enter a **UK postcode** (e.g. `SW1A 1AA`, `LS1 1BA`, `EX1 1AA`)
4. Set your **min/max distance** and **max stray radius**
5. Click **🗺️ Generate Routes**

Routes appear in the left panel. Click any route card to highlight it on the map.

## How It Works

### Postcode → Coordinates

`postcodes.io` resolves any UK postcode to latitude/longitude with no API key required.
Falls back to ORS geocoding if postcodes.io is unavailable.

### Route Generation (OpenRouteService)

Each route is generated via a **POST** to:
```
https://api.openrouteservice.org/v2/directions/foot-walking/geojson
```

with the round-trip option:
```json
{
  "options": {
    "round_trip": {
      "length": 6000,   // target metres
      "points": 3,       // intermediate waypoints (2–6)
      "seed": 42         // RNG seed — varied per route
    }
  },
  "extra_info": ["waytype", "surface"]
}
```

Multiple routes are generated by varying `seed`, `length`, and `points`.

### Footpath % Estimate

ORS returns `waytype` data for each segment. Segments classed as
`footway` (7), `path` (4), `track` (5), or `steps` (8) count as footpath-like.

```
footpath% = (footpath-like coordinate points) / (total coordinate points) × 100
```

### Repetition Score

The route geometry is sampled into a ~30 m grid. Any cell visited more than once
contributes to the repetition score:

```
repetition% = (retraced cell visits) / (total cell visits) × 100
```

A clean loop scores near 0%; a pure out-and-back scores ~50%+.

### Max Stray / Radius

The Haversine distance from the start point to every route coordinate is computed.
The maximum value is shown as "Max stray". Routes exceeding 1.5× the max stray
radius are discarded (the rest are shown with a warning badge).

## Limitations & Notes

- ORS round-trip routing is **not deterministic** beyond the seed — actual routes vary.
- Footpath % and repetition are **estimates** from OSM data; always verify on the ground.
- The free ORS tier limits you to ~2,000 requests/day. Generating 8 routes uses 8 requests.
- Routes that stray beyond your radius are shown with a ⚠️ badge — the ORS algorithm doesn't guarantee
  a bounding box; it only uses the seed to vary the shape.
- Always check rights of way, conditions, and access before walking a route.
